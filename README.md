# Molfoid Bot 🤖

A rude, cute, tsundere anime girl AI chatbot for Discord.

## Features

- 💬 AI chat powered by Groq (`openai/gpt-oss-120b`)
- 🎴 GIF responses via Tenor
- ⚡ Slash commands: `/ask`, `/gif`, `/molfoid`
- 📨 Mention replies in servers
- 💌 DM support — chat 1-on-1 with the bot
- 🎭 Tsundere personality (rude but secretly caring)
